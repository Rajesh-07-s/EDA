# Heart Attack Analysis – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** of a heart attack dataset to understand the factors that influence heart attack risk.  
The goal is to analyze patterns, trends, and relationships between medical attributes and heart disease occurrence using data visualization and statistics.

---

## Objectives
- Understand the structure and quality of the dataset  
- Identify important features related to heart attacks  
- Analyze correlations between medical parameters  
- Visualize trends using graphs and plots  
- Gain insights that may help in early risk identification  

---

## Dataset Description
The dataset contains medical information of patients, including:

- Age  
- Sex  
- Chest pain type  
- Resting blood pressure  
- Cholesterol level  
- Fasting blood sugar  
- Resting ECG results  
- Maximum heart rate achieved  
- Exercise-induced angina  
- ST depression  
- Target (presence or absence of heart disease)  

 **Dataset Source:** (https://www.kaggle.com/datasets/sukhmandeepsinghbrar/heart-attack-dataset/data)

## Steps Performed in EDA
1. Data loading and inspection  
2. Handling missing values  
3. Data cleaning and preprocessing  
4. Statistical summary of features  
5. Univariate analysis  
6. Bivariate and multivariate analysis  
7. Correlation analysis  
8. Data visualization using plots and charts  

---

##  Visualizations
The following visualizations were used:
- Bar charts  
- Histograms  
- Box plots  
- Heatmaps  
- Count plots  
- Scatter plots  

These helped in understanding data distribution and feature relationships.

---

##  Key Insights
- Certain features like **age, cholesterol, chest pain type, and heart rate** show strong relationships with heart attack risk  
- Males show higher heart attack occurrence compared to females  
- Exercise-induced angina and ST depression are important indicators  
- Correlation heatmap highlights significant feature dependencies
